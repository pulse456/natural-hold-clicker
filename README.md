# 自然长按连点器

Windows 图形化长按连点工具。普通短按完全按原样传递；按住选定鼠标键达到阈值后，自动转换为带自然时间波动的连续点击。

适用于本地/单机且接受 Windows 模拟输入的 FPS 游戏：短按仍保持半自动武器的正常单发操作，长按则转换为连续点击，实现类似全自动的持续开火。点击频率、间隔波动和长按阈值均可调节。

可直接从项目的 **Releases** 页面下载 `自然长按连点器.exe`，无需安装 Python。

仓库内也保留了当前稳定版：[下载 Windows x64 可执行文件](bin/natural-hold-clicker-windows-x64-v1.9.0.exe)。

## 两种触发策略

- **稳定长按**：短按保持原样；按住达到可调阈值后进入目标点击频率。
- **渐进连点**：真实首发立即响应，继续按住时先慢速点击，并在约 350 ms 内逐渐加速到目标频率。

原“极速触发”与 30 ms 的稳定长按行为重合，已合并到稳定长按；原“即时点按（全部转换）”已移除。所有模式都会忽略程序自身生成的事件，并在松开、暂停、F12 或退出时确保抬起按键。

## 游戏界面静默暂停

启用界面检测后，可以选择“仅检测背包时钟”或“检测背包时钟＋技能左键”；检测频率可选 `30 / 40 / 60 Hz`，默认 40 Hz：

- **仅检测背包时钟**：只在背包界面静默保护，并跳过鼠标模板匹配；适合不希望任何技能提示影响开火的配置。
- **背包时钟＋技能左键**：同时检测背包和技能按住提示，保留弓箭、手雷等技能保护。

- 物理触发键按下时如果已发现背包时钟、技能鼠标图标或已生效的按键预暂停，本次按住永久锁定保护，直到物理键松开。
- 按下时如果没有任何阻断状态，本次按住永久锁定连点；后续视觉误识别只更新后台状态，不会打断本次连点。
- 没有物理按住时，所选图标连续明确消失达到用户设置的确认帧数后解除后台阻断；默认 3 帧，可在 `1–10` 帧之间调整。
- 自动暂停和恢复不播放提示音，不影响真实鼠标单击。`F8` 手动暂停/继续仍然独立有效。

视觉状态在每次物理按下时只决策一次，形成双向锁定：技能状态不会因漏检恢复连点，正常战斗也不会因误检停止连点。`F8`、`F12` 和按下后新触发的自定义按键预暂停仍具有更高优先级，可以立即中断。3 帧消失确认在 30/40/60 Hz 下分别约为 100/75/50 ms；推荐从 40 Hz、3 帧开始，需要更快刷新时选择 60 Hz。

识别针对项目样本中的 1920×1080 界面调校，也会按同为 16:9 的主屏分辨率缩放区域和模板。截屏后端按 `DXCam → MSS → Pillow` 自动降级；在测试机器上 DXCam 的单次“截屏 + 识别”通常约 1–3 ms。60 Hz 相比 40 Hz 的检测轮询量增加 50%，具体资源占用取决于硬件和截屏后端。

鼠标左键识别使用多背景轮廓模板。v1.9.0 将触发阈值从 `0.62` 提高到 `0.70`：当前 24 张鼠标左键正样本最低约 `0.846`，常规负样本最高约 `0.586`；截图中的中键操作提示即使脱离实际检测框单独测试也只有约 `0.648`，均不会触发。搜索位置和模板尺寸没有放大，避免把右侧其他操作提示误认为左键图标。

## 自定义按键预暂停

可以添加最多 12 条按键预暂停规则，为每个技能键设置独立暂停时间。点击规则中的按键输入框，再直接按下目标按键即可自动识别：

- 支持常用键盘按键、功能键、小键盘按键和组合键中的单个实体键。
- 支持鼠标左键、右键、中键、侧键 1 和侧键 2；当前连点触发键不能同时绑定。
- 每条规则可以单独启用、停用、删除，暂停时间范围为 `10–10000 ms`。
- 长按键盘键只在首次按下时触发，系统自动重复不会反复延长暂停；松开后再次按下会建立新的暂停窗口。
- 多个按键暂停窗口与图标检测采用“或”逻辑：只要任一按键计时尚未结束，或任一阻断图标仍存在，自动连点就不会恢复。
- 按键预暂停和自动恢复不播放提示音，也不会把自动恢复误当成手动 F8 继续。

例如技能键 `Q` 设置为 220 ms：按下 Q 后连点会立即停止，从而覆盖技能图标延迟出现的空窗；如果在这 220 ms 内按下鼠标触发键，本次鼠标按住会直接锁定保护，计时到期也不会在中途恢复连点。

为保证紧急控制可靠，当前暂停/继续快捷键以及 `F12` 紧急停止键不能被添加为预暂停键。录入按键时的那一次输入会被程序截获，不传给游戏；保存后实际使用技能键时，按键会正常传给游戏，仅自动连点被静默暂停。

## 使用

1. 打开 `自然长按连点器.exe`。
2. 设置每分钟点击次数、间隔波动和长按阈值，点击“保存并应用”。
3. 按住设定的鼠标键开始，松开立即结束。
4. 默认按 `F8` 暂停或继续；任何时候按 `F12` 都会紧急停止并进入暂停状态。

长按阈值可设置为 `30–1500 ms`。输入低于 30 的值（例如 `0`）并保存时，会自动修正并回填为 `30`。30 ms 等效于原“极速触发”的触发时间；建议先从 `80–150 ms` 测试，因为阈值越低，较慢的普通单击越容易被判定为长按并产生额外点击。该阈值只负责区分短按和长按，不影响程序对自身生成事件的隔离保护。

状态提示音默认开启：启用连点时播放短促升调，暂停时播放短促降调，F12 紧急停止使用更明显的低音。可在界面中关闭提示音；普通单击和每次连点不会发声。

程序采用单实例保护：重复双击不会启动多个鼠标监听器。如果旧窗口仍在运行，新实例会提示先关闭旧窗口，避免多个版本同时生成互相冲突的鼠标事件。若暂停/紧急停止快捷键已被占用，连点功能会保持关闭，而不是在缺少安全快捷键的情况下继续运行。

单文件 EXE 运行时会由 PyInstaller 解压到系统 `_MEI...` 临时目录。管理员重启会显式标记为独立新实例，避免新旧进程复用同一个临时目录并触发清理警告。若在普通退出时仍偶发看到临时目录清理警告，通常是杀毒软件或系统短暂占用文件；该警告不代表连点器运行失败。

视觉保护采用按次输入双向锁存：按下瞬间处于保护状态就锁定暂停，处于正常状态就锁定连点；物理松开后清除本次决策。这样同时避免技能过程中漏检导致提前释放，以及正常开火过程中误检导致断触。

界面底部的“连点诊断”会记录连续点击任务当前是否运行，以及最近一次停止是由物理鼠标松开、按键预暂停、F8/F12/界面按钮或输入设置重置引起。它只记录本工具看到的状态，不影响点击时序，便于复现偶发断触时区分视觉误检和真实输入中断。

“自然节奏漂移”只让相邻点击间隔产生轻微关联；“低概率短停顿”已拆分为独立选项并默认关闭。启用短停顿后，每个间隔约有 `1.8%` 概率额外延长基础间隔的 `30%–75%`，可能产生可感知的单次节奏空隙，但不会改变视觉保护状态。

暂停后即使鼠标仍处于按下状态，也必须松开并重新长按才会再次启动。这样可以避免恢复时意外连点。

## 安全设计

- 鼠标监听会忽略所有由程序注入的事件，不会形成自我触发循环。
- 松开、暂停和退出都会取消当前任务；若正在按下，会确保补发抬起事件。
- 短按不拦截、不重放，因此普通单击没有人为延迟。
- 界面识别只截取两个小区域，不读取、修改或注入游戏进程。
- 设置保存在 `%LOCALAPPDATA%\NaturalHoldClicker\config.json`。

部分使用管理员权限运行的程序可能拒绝接收普通权限程序发出的输入。遇到这种情况，可用相同权限启动本工具。

## FPS 游戏兼容性

推荐仅在本地单机游戏或游戏规则明确允许的场景中使用。本工具不会读取、修改或注入游戏进程，只通过 Windows 输入接口生成鼠标事件。

如果桌面程序中有效、游戏内无效，请观察界面底部的“输入诊断”：

1. 如果“检测到物理按下”不增加，请用“管理员重启”启动本工具，并让工具与游戏处于相同权限级别。
2. 如果物理按下和已生成点击都增加，但游戏没有反应，请依次尝试“游戏兼容模式”和“窗口消息模式（旧游戏）”。更换模式后需要松开鼠标并重新长按。
3. 某些使用 Raw Input、DirectInput 或主动过滤模拟输入的游戏不会接受任何普通 Win32 模拟方式。这种情况下诊断计数会正常增加，但游戏仍不会响应；需要针对具体游戏确认其输入接口，不能通过提高点击频率解决。

## 从源码运行和构建

- 运行源码：使用 Python 3.10 或更高版本，先执行 `pip install -r requirements-build.txt`，再执行 `python human_clicker.py`。
- 运行测试：执行 `python -m unittest discover -v`。
- 重新生成 EXE：在 PowerShell 中执行 `./build.ps1`。脚本会创建或复用隔离的构建环境，并把识别模板一起打包。
