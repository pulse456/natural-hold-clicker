# 自然长按连点器

Windows 图形化长按连点工具。普通短按完全按原样传递；按住选定鼠标键达到阈值后，自动转换为带自然时间波动的连续点击。

适用于本地/单机且接受 Windows 模拟输入的 FPS 游戏：短按仍保持半自动武器的正常单发操作，长按则转换为连续点击，实现类似全自动的持续开火。点击频率、间隔波动和长按阈值均可调节。

可直接从项目的 **Releases** 页面下载 `自然长按连点器.exe`，无需安装 Python。

## 使用

1. 打开 `自然长按连点器.exe`。
2. 设置每分钟点击次数、间隔波动和长按阈值，点击“保存并应用”。
3. 按住设定的鼠标键开始，松开立即结束。
4. 默认按 `F8` 暂停或继续；任何时候按 `F12` 都会紧急停止并进入暂停状态。

状态提示音默认开启：启用连点时播放短促升调，暂停时播放短促降调，F12 紧急停止使用更明显的低音。可在界面中关闭提示音；普通单击和每次连点不会发声。

程序采用单实例保护：重复双击不会启动多个鼠标监听器。如果旧窗口仍在运行，新实例会提示先关闭旧窗口，避免多个版本同时生成互相冲突的鼠标事件。若暂停/紧急停止快捷键已被占用，连点功能会保持关闭，而不是在缺少安全快捷键的情况下继续运行。

暂停后即使鼠标仍处于按下状态，也必须松开并重新长按才会再次启动。这样可以避免恢复时意外连点。

## 安全设计

- 鼠标监听会忽略所有由程序注入的事件，不会形成自我触发循环。
- 松开、暂停和退出都会取消当前任务；若正在按下，会确保补发抬起事件。
- 短按不拦截、不重放，因此普通单击没有人为延迟。
- 设置保存在 `%LOCALAPPDATA%\NaturalHoldClicker\config.json`。

部分使用管理员权限运行的程序可能拒绝接收普通权限程序发出的输入。遇到这种情况，可用相同权限启动本工具。

## FPS 游戏兼容性

推荐仅在本地单机游戏或游戏规则明确允许的场景中使用。本工具不会读取、修改或注入游戏进程，只通过 Windows 输入接口生成鼠标事件。

如果桌面程序中有效、游戏内无效，请观察界面底部的“输入诊断”：

1. 如果“检测到物理按下”不增加，请用“管理员重启”启动本工具，并让工具与游戏处于相同权限级别。
2. 如果物理按下和已生成点击都增加，但游戏没有反应，请依次尝试“游戏兼容模式”和“窗口消息模式（旧游戏）”。更换模式后需要松开鼠标并重新长按。
3. 某些使用 Raw Input、DirectInput 或主动过滤模拟输入的游戏不会接受任何普通 Win32 模拟方式。这种情况下诊断计数会正常增加，但游戏仍不会响应；需要针对具体游戏确认其输入接口，不能通过提高点击频率解决。

## 从源码运行和构建

- 运行源码：使用 Python 3.10 或更高版本执行 `python human_clicker.py`。
- 运行测试：执行 `python -m unittest -v test_human_clicker.py`。
- 重新生成 EXE：在 PowerShell 中执行 `./build.ps1`。脚本会首次自动创建隔离的构建环境。
